277: 11. Guía de Instalación y Despliegue Local
279: 11.1. Requisitos Previos de Software
284: 11.2. Configuración de la Base de Datos en MySQL
285: 1. Iniciar los servicios de Apache y MySQL desde el panel de control de XAMPP.
286: 2. Abrir el navegador web e ingresar a phpMyAdmin: http://localhost/phpmyadmin
287: 3. Crear una nueva base de datos llamada tf_pendientes con cotejamiento utf8mb4_unicode_ci.
288: 4. Importar el archivo del esquema relacional y datos iniciales (database.sql o seeders del proyecto).
289: 5. Verificar que se hayan creado exactamente las 11 tablas y los triggers trg_tareas_after_insert y trg_tareas_after_update.
290: 11.3. Puesta en Marcha del Backend (PHP)
291: 1. Ubicar los archivos del backend en el directorio htdocs de XAMPP: C:\xampp\htdocs\tf-pendientes\backend
292: 2. Abrir una terminal de comandos en la carpeta backend y verificar las dependencias de Composer:
294: 3. Verificar la configuración de base de datos en config/database.php (usuario 'root' y contraseña vacía por defecto en XAMPP).
295: 4. Garantizar que la carpeta uploads/tickets/ cuente con permisos de escritura para la subida de imágenes.
296: 5. Comprobar la conectividad del backend abriendo en el navegador: http://localhost/tf-pendientes/backend/catalogos
297: 11.4. Puesta en Marcha del Frontend (React + Vite)
298: 1. Abrir una terminal en el directorio frontend del proyecto:
300: 2. Instalar las dependencias de Node.js:
302: 3. Iniciar el servidor de desarrollo ultrarrápido de Vite:
304: 4. Abrir en el navegador web la dirección asignada: http://localhost:5173
305: 5. Iniciar sesión con las credenciales administrativas de prueba (o las configuradas en la base de datos).
306: 11.5. Configuración para Acceso en Red Local (LAN)
308: 1. Obtener la dirección IP local de la computadora servidora ejecutando ipconfig en PowerShell (ejemplo: 192.168.1.150).
309: 2. En el frontend, iniciar Vite exponiendo el host a la red: npm run dev -- --host
310: 3. En el archivo src/lib/axios.js, configurar baseURL apuntando a la IP local: http://192.168.1.150/tf-pendientes/backend
311: 4. Permitir el puerto 5173 en el Firewall de Windows para conexiones entrantes de red privada.
